## 🔬 Projeto principal

### [Forensic Artifact Triage Toolkit](https://github.com/Berguy/forensic-triage-toolkit)

Toolkit Python de triagem forense para sistemas Windows comprometidos, projetado desde o primeiro commit com conformidade normativa:

- **ISO/IEC 27037, 27041, 27042 e 27043** — coleta, preservação, análise e relato de evidência digital
- **Resolução CNJ nº 552/2021** — requisitos da perícia digital no Judiciário brasileiro
- **MITRE ATT&CK** — mapeamento de artefatos para técnicas de adversário
- **Integridade criptográfica** — hashing multialgoritmo e cadeia de custódia desde o manifesto de evidências

Desenvolvimento em sprints, com suíte de testes e CI desde o primeiro dia.

> 🚧 Em desenvolvimento ativo — Sprints 1-3 (Core, Coletores, Parsers) concluídas · Sprint 4 (Analyzers) em andamento
